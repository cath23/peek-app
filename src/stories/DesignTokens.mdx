# Design Tokens

Peek is **token-driven and pixel-perfect** — components reference these tokens,
never raw hex. Every swatch below reads a live CSS variable, so it reflects the
theme selected in the **Theme** toolbar (☾). The names are the ones you use in
code: a color token `bg-surface` is the Tailwind class `bg-bg-surface`; a type
token `body-2` is `text-body-2`.

> Source of truth: `src/index.css` (CSS variables, per theme) and
> `tailwind.config.js` (type / radius / shadow scales).

## Typography

Font family is **Geist**. The ramp pairs headings, body, and component-specific
sizes. Component tokens (`btn-*`, `input-*`, `chip`) are deliberately explicit —
see the tw-merge pitfall in `CLAUDE.md` before reusing them in shared components.
